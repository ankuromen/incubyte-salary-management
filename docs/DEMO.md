# Demo Video Script (2–3 minutes)

Record a screen walkthrough showing the deployed or local app. Suggested flow:

## 1. Intro (15 s)

- Show login page: “Salary Management — HR admin portal.”
- Login with default credentials (`admin@company.com` / `Admin@123`).

## 2. Dashboard (30 s)

- HR Dashboard with **workforce snapshot** KPIs.
- Point out **salary distribution** and **employees by country** charts.
- Click **Open full analytics**.

## 3. Employees at scale (45 s)

- **Employees** list — mention ~10,000 records.
- Use **search** (name/email).
- Filter by **country** or **department**.
- Show **pagination** (page 1 of many).
- Click **Add Employee** → searchable dropdowns for country/department/job title.
- Save or cancel.

## 4. CRUD (30 s)

- **Edit** an employee → change salary → save.
- **Delete** → custom confirmation modal → confirm.

## 5. Analytics (30 s)

- Full **Analytics** page: charts + tables.
- Country breakdown (min / avg / max).
- Job title averages with **pagination**.
- Department compensation chart.

## 6. Admin (15 s, optional)

- **Admin Accounts** → add a second admin (optional).

## 7. Close (10 s)

- Mention stack: React + Express + Prisma + SQLite, TDD, 10k seed.
- Show repo / README / live URLs.

---

**Recording tips**

- 1080p, hide unrelated browser tabs.
- Use deployed URLs if available; otherwise localhost is fine.
- Upload to Loom / YouTube (unlisted) and link in README.
