# GLOBAL EXECUTION RULES

Follow these rules for ALL phases.

## Development Method

Strict TDD:

1. Write failing tests
2. Implement minimal code
3. Refactor
4. Commit

---

## Commit Rules

Small incremental commits only.

Never combine multiple features into one commit.

---

## Code Quality

Must:

* production-ready
* strongly typed
* modular
* clean architecture
* maintainable

Avoid:

* shortcuts
* giant files
* skipped tests

---

## Phase Execution

Implement ONE phase at a time.

Stop after phase completion.

Wait for next instruction.

Never continue automatically to next phase.

---

## Response Format

After completing phase, return:

Completed:
[list]

Tests written:
[list]

Commits created:
[list]

Ready for next phase.
